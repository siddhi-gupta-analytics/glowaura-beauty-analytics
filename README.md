# GlowAura Beauty Analytics

End-to-end data analytics project on a fictional Indian beauty and cosmetics retailer, **GlowAura Beauty**, using Excel, SQL, Python and Power BI.

## Business Problem
GlowAura sells skincare, makeup and haircare products through online and offline stores across multiple Indian cities. This project cleans raw sales data and finds out what drives revenue, profit and customer loyalty.

## Business Questions
1. Which product categories generate the most revenue and profit?
2. Which channels, cities and stores perform best (online vs offline)?
3. What is the ROI of each marketing campaign?
4. How many customers are repeat buyers, and where does churn happen?
5. How much do discounts reduce profit margin?

## Dataset
Synthetic dataset (Jan 2024 - Dec 2026, INR) with 6 related tables: Customers, Products, Orders, Order_Details, Stores and Marketing_Campaigns. The raw data contains real-world issues such as nulls, duplicates, inconsistent text and mixed date formats.

## Tools Used
- **Excel:** data profiling, pivot tables, KPI dashboard
- **SQL (MySQL):** cleaning, data modelling, business queries
- **Python (Pandas, Matplotlib, Seaborn):** cleaning, EDA, RFM customer segmentation
- **Power BI:** interactive dashboard
